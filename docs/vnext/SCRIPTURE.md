# Scripture attribution and scope

The Bible reader bundles ten chapters of the **World English Bible (WEB)**:
Romans 7–9, John 14–16, Psalms 23 and 46, Philippians 3–4. These are real complete
chapters, not generated summaries. The selector lists only the bundled chapters;
the application explicitly describes the ten-chapter offline demo library.

Source retrieved 19 November 2026: `https://bible-api.com/{book}+{chapter}?translation=web`.
Verse text is reproduced without paraphrasing; only leading/trailing whitespace
is removed. The featured passage and memory practice use this same bundled text.

The World English Bible is in the **public domain**. The translation name is a
trademark identifying the translation, not an endorsement of this prototype.
Publisher and license information: https://ebible.org/web/ and
https://ebible.org/eng-web/copyright.htm.

No ESV, NIV, Crossroads pastor notes, sermons, recordings or artwork are included.
Explore contains original demo readings, labeled as such. This preview makes no
claim that its editorial content is official Citizen Church teaching.

The historical prototype used a KJV memory exercise. Existing saved completion
and partial answers are retained; its five-word exercise remains compatible and
uses a clearly attributed KJV excerpt (public domain in the United States).
New Scripture reading and verse selection use WEB exclusively.
