## Implementation
- 11D.1: explicit unavailable/restricted states preserved, no cache, no fabricated empty calendar, fresh independent reads on recovery. 
- 11D.2: existing 11A session owner now propagates AbortSignal to reader and verifier via a second internal argument (not an input claim). 12s whole-read deadline, 5s verifier deadline, configurable bounded maxima. Existing per-call provider timeout retained. 11B propagates cancellation to its fake transport, checks between requests and before projection. New server-only s11d-resilient-transport wraps only the composed 11C transport; standalone 11B no-retry tests remain authoritative. At most two attempts by default, three hard maximum, for explicit 502/503/504 or 429 with valid synthetic retry hint. Bounded backoff; no retry on exceptions, 401/403/404, redirects, malformed results or writes. Actual HTTP Retry-After parsing and live transport not implemented.
- 11D.3: record removal aborts active work, logout/account switch/withdrawal/sweep/shutdown all use same session owner. Kill switch clears all pending exchanges even with no consent records. Existing before/after permission checks stay intact. No cross-user coalescing or result cache.
- 11D.4: per-session active read cap two; per-tenant-process transport cap eight unresolved calls and 120 attempts per fixed 60s window, including retries. Candidate conservative defaults; no queue, no per-person telemetry. Noncooperative transport retains capacity until it actually settles, while caller returns on deadline; never claims abort can forcibly stop arbitrary JS or remote work. A stuck dependency can exhaust capacity; synthetic process restart/operational recovery required. Limits are process-local, not distributed security/rate-limit guarantees; no IP or login throttling implemented here.
- 11D.5: partial scans and late responses never yield a member view; provider recovery requires new successful membership and source read, no fabricated data. Existing coarse aggregate audit remains sole telemetry; no raw data logs.
- 11D.6: executable adversarial cases target outages/recovery, retry statuses and cancellation, total deadline, verifier expiry, concurrent accounts, shutdown, consent races, quota/clock rollback, noncooperative dependency, partial retrieval and mixed read stress. Full existing CI/visual and device gate required. Syntax checked when authoring, no Node test execution or exact-head CI result yet.
